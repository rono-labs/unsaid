# Held-out test corpus
Generated by `make_test.py` (stdlib, seed 2026) -> `cases.json`; run `python3 bench/test/make_test.py` from the project dir.
Written blind: the detector source and dev corpus were never read. Secrets are random with realistic prefixes/lengths.
60 cases, 112 labels (every label is an exact substring; cards pass Luhn, IBAN passes mod-97, checked in the script).
Counts: IP_ADDRESS 13, PERSON 10, PASSWORD 9, SECRET 8, EMAIL 6, PHONE 6, LOCATION 5, JWT 4, ORG 4, STRIPE_KEY 3, USERNAME 3, 2 each of AWS_ACCESS_KEY, AWS_SECRET_KEY, GITHUB_TOKEN, MAC_ADDRESS, SLACK_TOKEN, SSN, URL_SECRET; 1 each of the rest.
Decoys: 18 cases have zero labels and 5 more are mostly decoy (<=1 label), ~38% of cases. Decoys: SHAs, UUIDs, sri hashes, digests, data URIs, versions, placeholders, Luhn-failing cards.
