# Benchmark corpus

40 synthetic cases (`cases.json`) for a secret/PII detector, generated by `make_corpus.py` (stdlib only, `random.seed(7)` plus a seeded RNG, so output is reproducible; run `python3 bench/corpus/make_corpus.py` from the project dir).
All secrets are random fakes with realistic prefixes and lengths. Cards pass Luhn and IBANs pass mod-97. The script asserts both, and that every label is an exact substring of its text.
The corpus was written blind to the detector, and nothing under `project/src` was read.
Decoys: 7 cases have zero labels and 24 have 2 or fewer. Decoys include SHAs, UUIDs, sha256 and image digests, base64 blobs, versions, localhost, placeholders, and Luhn-failing cards.
Counts (104 labels): EMAIL 14, IP_ADDRESS 10, PERSON 10, PASSWORD 7, PHONE 6, SECRET 6, LOCATION 5, AWS_ACCESS_KEY 4, AWS_SECRET_KEY 3, CREDIT_CARD 3, IBAN 3, ORG 3, STRIPE_KEY 3, and 2 each for GITHUB_TOKEN, GOOGLE_API_KEY, JWT, MAC_ADDRESS, PRIVATE_KEY, SENDGRID_KEY, SSN, TWILIO_KEY, URL_SECRET, USERNAME.
1 each: ANTHROPIC_KEY, GITLAB_TOKEN, HF_TOKEN, NPM_TOKEN, OPENAI_KEY, SLACK_TOKEN, SLACK_WEBHOOK.
